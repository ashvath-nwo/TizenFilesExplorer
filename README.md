# TizenFilesExplorer
Tizen Files Explorer. It can read and write to Downloads, music, videos, documents folders in the internal NAND of the TV
#
You can use Tessel to access media files and play it
#
Minimum Tizen OS Version = 4.0
#
_Uses the official Tizen Filesystem API_
# Tested Device
UA32N4200 (Samsung 4 Series 32 Inch) running Tizen OS 4.0 version 1400.2
